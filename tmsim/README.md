# tmsim - a time machine simulator for the Mini Micro

## usage

If mounted to `/usr`, it should autostart when using `reboot`.

If mounted to `/usr2`, run the following to start the game:

```basic
load "/usr2/startup"
run
```

## ai disclaimer

- consultation on Miniscript coding patterns and best practices
- writing of reference documentation and code in `docs/ai/`
- creation of graphics and sound for the Mini Micro under `assets/`

> NOTE: all game assets agentically created will be explicitly cited either at the top of each file or some other manner (TBD)

Agentic AI has *not* been used for the following:

- all game story elements and all game text
- all gameplay elements and mechanics
- all game code (the overall design and its implementation)
- all graphics and sound (under `assets/`) without an explicit citation of being agentically created
